The whole life of a security agency, as one tracked workflow

Speaker notes — slide 3: This is the heart of SAMS: the life of an ex-servicemen security agency as one workflow. Technical architecture · QCBS 2(a) · paras 12, 15.1
Three tiers, inside the NIC perimeter
Sakuraj Technologies · SAMS for DGR · Technical presentation, 16 Nov 2026 · GEM/2026/B/8153327 · Screens are illustrative designs with sample data16 / 23
Speaker notes — slide 16: SAMS is a three-tier application. Users arrive from the DGR website. Inside NIC, only HTTPS is open to the internet; the web tier runs ASP.NET Core MVC on .NET 10, the current long-term-support release; application services handle the workflow, the alerts scheduler, reports, e-mail and APIs; and SQL Server sits on a private network with no internet route, encrypted and backed up nightly. Outbound traffic is only the NIC mail relay and the SMS gateway. There are no third-party scripts.
